# swap 与 RAID（mdadm）

- 日期：2026-10-17（W3-D3）
- 考点：RHCSA EX200 —— 不破坏数据地向系统添加 swap；（扩展）软件 RAID
- 环境：Rocky Linux 10（VirtualBox），datavg、sdg、sdh
- 状态：完成
- 来源：根据课程对话和终端记录整理

## 目标

加 swap 文件和 swap LV 并开机生效；用两块空盘建 RAID 1，模拟坏盘、换盘，重启验证。

## 关键概念

- swap：内存紧张时把冷页写到磁盘；不是内存替代品，频繁换入换出（抖动）会很慢；没有 swap 且内存耗尽 → OOM Killer 杀进程（`journalctl -k | grep -i "out of memory"`）。
- 流程：准备空间 → `mkswap` → `swapon` → fstab（挂载点 `none`，类型 `swap`）→ `swapon -a` 验证。
- swap 文件：`dd` 创建（不能有空洞）、`chmod 600`（内容是内存数据，可能含密码）；fstab 直接写文件路径。`pri=N` 数字大优先。
- RAID 0 条带无冗余；1 镜像；5 = n−1，坏 1 块（XOR 分布式校验）；6 = n−2，坏 2 块；10 = n/2，每组镜像坏 1 块。
- RAID 5 重建要整盘读一遍，大盘耗时长，期间再坏一块或读到坏扇区就丢数据 → 大盘用 RAID 6/10。
- **RAID 不是备份**：误删、勒索病毒都会同步到所有盘。
- mdadm 在成员盘上写超级块，开机自动组装；没有 `/etc/mdadm.conf` 可能变成 md127 → fstab 用文件系统 UUID。
- `/proc/mdstat`：`[UU]` 健康，`[U_]` 降级，`(F)` 故障盘。
- write-intent bitmap：记录最近写过的区域，盘被拔出再加回时只同步这些区域。

## 关键步骤

```bash
# swap 文件
sudo dd if=/dev/zero of=/swapfile bs=1M count=512 status=progress
sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile
echo "/swapfile none swap defaults 0 0" | sudo tee -a /etc/fstab

# swap LV + 优先级
sudo lvcreate -n swap2 -L 512M datavg && sudo mkswap /dev/datavg/swap2
echo "/dev/datavg/swap2 none swap defaults,pri=10 0 0" | sudo tee -a /etc/fstab
sudo swapon -a; swapon --show

# RAID 1（先确认空盘：本次空盘是 sdg、sdh，不是讲义写的 sdh、sdi）
sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdg /dev/sdh
sudo mkfs.xfs /dev/md0
sudo mdadm --detail --scan | sudo tee -a /etc/mdadm.conf
echo "UUID=$(sudo blkid -s UUID -o value /dev/md0) /mnt/raid xfs defaults 0 0" | sudo tee -a /etc/fstab

# 模拟坏盘与换盘
sudo mdadm /dev/md0 --fail /dev/sdh
sudo mdadm /dev/md0 --remove /dev/sdh
sudo mdadm /dev/md0 --add /dev/sdh
```

## 验证

| 检查项 | 命令 | 预期结果 | 结果 |
|---|---|---|---|
| swap 文件生效 | `free -h` | 2.0G → 2.5G | ✅ |
| swap2 优先级 | `swapon --show` | PRIO 10 | ✅ |
| 阵列健康 | `cat /proc/mdstat` | `[2/2] [UU]` | ✅ |
| 坏盘后降级 | `cat /proc/mdstat` | `[U_]`、`sdh[1](F)` | ✅ `State : clean, degraded` |
| 降级时数据可读 | `md5sum -c /root/raid.md5` | OK | ✅ |
| 内核日志 | `journalctl -k` | 记录坏盘 | ✅ `Disk failure on sdh, disabling device` |
| 加回后 | `cat /proc/mdstat` | `[UU]` | ✅ 显示 `re-added`，立刻恢复（bitmap：降级期间没有写入，无需同步） |
| 重启后 | `swapon --show`、`/proc/mdstat`、`df -hT`、`md5sum -c` | 3 个 swap、md0 `[UU]`、全部挂载、数据 OK | ✅ 名字仍是 md0 |

## 踩坑

- **设备名又变了**：data1/data2 从 sdg 跑到 sdi（周二调整过盘顺序）。`wipefs /dev/sdi` 发现 GPT 签名后停下，用 `lsblk -f` 确认，改用真正的空盘 sdg、sdh。/mnt/data1、/mnt/data2 因 fstab 用 UUID 照常挂载。
- `mdadm --create --level=1 ...` 漏了 `/dev/md0` → mdadm 把 `/dev/sdg` 当阵列名，报 `exists but is not an md array`，未做任何改动。
- `blkid UUID -o value /dev/md0` 漏了 `-s` → 输出 UUID、512、xfs 三行，往 fstab 写进三行垃圾 → `findmnt --verify` 报 2 parse errors + `unreachable source: xfs` → 确认 `tail -4` 后 `sed -i '$d'` 删三次，重新写正确的一行。教训：`$(...)` 拼进配置前先单独执行看输出。
- `findmnt --verify` 对多个 swap 报 `target specified more than once`、对 swap 文件报 `non-bind mount source ... regular file`，都是无害警告。
- `chmmod`、`swapon all`（应为 `-a`）、`dd size=`（应为 `count=`）拼写错误。
- 达标题：swap 文件的 fstab 写成了 `/dev/md1`，应为 `/swapfile none swap defaults 0 0`。

## 回忆题

1. （概念）4 块 1T 盘做 RAID 0 / 5 / 10，可用容量和容错各是多少？
<details><summary>答案</summary>

RAID 0：4T，0 块；RAID 5：3T，1 块；RAID 10：2T，每组镜像各 1 块。
</details>

2. （操作）加一个 1G 的 swap 文件并开机生效。
<details><summary>答案</summary>

`dd if=/dev/zero of=/swapfile2 bs=1M count=1024; chmod 600 /swapfile2; mkswap /swapfile2; swapon /swapfile2; echo "/swapfile2 none swap defaults 0 0" | sudo tee -a /etc/fstab; swapon -a`
</details>

3. （排障）`/proc/mdstat` 显示 `[U_]`，怎么处理？
<details><summary>答案</summary>

`mdadm --detail /dev/md0` 确认哪块盘故障 → `--fail`（若未自动标记）→ `--remove` → 换新盘 → `--add` → 看 `/proc/mdstat` 重建到 `[UU]` → 校验数据。
</details>
