## 目标

sed 负责"改"，awk 负责"算"：会安全地改配置文件，会按列筛选和计算。

## 关键概念

- sed 默认打印每一行、默认不改原文件；`-n` + `p` 只打印选中行；`-i` 才改文件。
- **写 sed 一律加 `-E`**，否则 `? + | ()` 是普通字符。
- 改配置的模板：`s/^#?关键字.*/关键字 新值/`（整行替换单个配置项）。
- `sed -i` 实际是：写临时文件 → 原文件改名为 `.bak` → 临时文件改名为原名。所以**新文件换了 inode**，原硬链接断开，`.bak` 就是原来那个 inode。
- 符号链接上 `sed -i` 会把链接替换成普通文件，要改目标需 `--follow-symlinks`。
- awk 默认按连续空白切分；`-F:` 指定分隔符；`$NF` 最后一列；`NR` 行号。
- awk 程序用单引号；Shell 变量用 `-v` 传入。
- 写 awk 前先 `head -3` 看分隔符和列号。

## 关键步骤

```bash
sed -n '100,105p' access.log
sed -i".bak.$(date +%F-%H%M%S)" -E 's/^#?MaxAuthTries.*/MaxAuthTries 3/' sshd_config
grep MaxAuthTries sshd_config sshd_config.bak*

awk '{sum += $NF} END {printf "%.3f\n", sum/NR}' access.log     # 平均响应时间
awk '$9 >= 500 {n++} END {printf "%.2f%%\n", n/NR*100}' access.log
awk '$1 == "192.168.1.13" {sum += $10} END {print sum}' access.log
awk -F: '$3 >= 1000 && $3 < 65534 {print $1}' /etc/passwd       # 普通用户
df -h | awk 'NR>1 && $5+0 > 10 {print $6, $5}'
```

## 踩坑

- `sed 's/^#?MaxAuthTries.*/.../'` 什么都没改 → 没加 `-E`，`?` 被当成普通问号 → 加 `-E`。
- 连续两次 `sed -i.bak`，第二次把第一次的备份覆盖了，最原始的配置丢失 → 备份名加时间戳。
- 以为 `.bak` 和原文件 inode 相同是因为"创建了硬链接" → 实际是**改名**（mv 不改 inode）。

## 回忆题

1. （概念）`sed -i` 之后，原来的硬链接为什么看不到新内容？
<details><summary>答案</summary>

sed -i 生成新文件并改名替换原文件名，新文件是新 inode；硬链接仍指向旧 inode（旧内容）。
</details>

2. （操作）不管有没有注释、原值多少，把 `#Port 22` 改成 `Port 2222`，带时间戳备份。
<details><summary>答案</summary>

`sed -i".bak.$(date +%F-%H%M%S)" -E 's/^#?Port .*/Port 2222/' sshd_config`
</details>

3. （排障）sed 命令没报错但文件没变化，按什么顺序检查？
<details><summary>答案</summary>

是否加了 `-i`；用了 `? + |` 是否加了 `-E`；`-E` 前是否有空格；先 `grep -n` 看原始行的真实格式（注释后是否有空格等）。
</details>
