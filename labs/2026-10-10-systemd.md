# systemd 与服务管理

- 日期：2026-10-10（W2-D5）
- 考点：RHCSA EX200 —— 启动/停止/检查服务；配置开机自启；引导到指定 target；设置默认 target
- 环境：Rocky Linux 10（VirtualBox）
- 状态：完成（热身 3/3，达标检查 9/9）
- 来源：根据课程对话整理

## 目标

会管服务、写单元文件、用 drop-in 改配置、设置默认 target。

## 关键概念

- `start` 管现在，`enable` 管开机；**RHCSA 要求重启后仍生效 → `enable --now`**。
- `restart` 中断服务；`reload` 让进程重读配置（常是 HUP）不中断 → 生产优先 reload。
- `disable` 后仍可手动启动或被依赖拉起；`mask` 链接到 `/dev/null`，彻底禁止。
- `enable` 本质：在 `WantedBy=` 指定的 target 的 `.wants/` 下建符号链接。`set-default` 改的是 `default.target` 链接。
- 单元文件优先级：`/etc/systemd/system`（管理员）> `/run` > `/usr/lib/systemd/system`（软件包，**不要直接改**）。
- 改已有服务用 drop-in：`/etc/systemd/system/xxx.service.d/*.conf`（**必须 .conf 结尾**）。
- 新建或修改单元文件后 `systemctl daemon-reload`。
- `After=` 只管顺序，`Wants=` 弱依赖，`Requires=` 强依赖。
- `Restart=on-failure`：被 TERM/INT/HUP/PIPE 终止**不重启**，被 KILL 杀死会重启；`always` 都重启。
- 脚本要直接在 `/usr/local/bin` 创建，从家目录 `mv` 过去会带着家目录的 SELinux 标签，systemd 启动时被拒（W4）。

## 关键步骤

```bash
sudo systemctl enable --now httpd
ls -l /etc/systemd/system/multi-user.target.wants/ | grep httpd
sudo systemctl mask httpd; ls -l /etc/systemd/system/httpd.service   # -> /dev/null

# 自定义服务
sudo tee /etc/systemd/system/hello.service << 'EOF'
[Unit]
Description=Hello Demo Service
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/hello.sh
Restart=on-failure
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload && sudo systemctl enable --now hello
systemctl show -p MainPID hello

# 手动 drop-in
sudo mkdir -p /etc/systemd/system/hello.service.d
printf '[Service]\nRestart=always\n' | sudo tee /etc/systemd/system/hello.service.d/override.conf
sudo systemctl daemon-reload; systemctl cat hello

sudo systemctl set-default multi-user.target
```

## 验证

| 检查项 | 命令 | 预期结果 | 结果 |
|---|---|---|---|
| on-failure + TERM | `kill -TERM 主PID` | 不重启 | ✅ |
| on-failure + KILL | `kill -9 主PID` | 自动重启，PID 变化 | ✅ |
| 重启后 httpd | `systemctl is-active httpd` | active | ✅（自述已完成） |

## 踩坑

- `systemctl edit hello` 保存后提示 `Found modifications outside of the staging area` / `new contents are empty, not writing file` → 内容写在了 "Edits below this comment will be discarded" 那行**下面** → 要写在顶部两段注释之间；或者手动建 drop-in 文件 + `daemon-reload`。

## 回忆题

1. （概念）`systemctl enable httpd` 背后做了什么？链接为什么建在 `multi-user.target.wants/`？
<details><summary>答案</summary>

在 `/etc/systemd/system/multi-user.target.wants/` 建指向单元文件的符号链接；因为单元文件里写了 `WantedBy=multi-user.target`。
</details>

2. （操作）写单元文件：backup-agent，运行 `/opt/agent/run.sh`，用户 backup，网络就绪后启动，崩溃 5 秒后重启，开机自启。
<details><summary>答案</summary>

```ini
[Unit]
Description=Backup Agent
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
ExecStart=/opt/agent/run.sh
Restart=on-failure
RestartSec=5
User=backup

[Install]
WantedBy=multi-user.target
```
然后 `daemon-reload` + `enable --now`。
</details>

3. （排障）写了 drop-in 但 `systemctl cat` 看不到它，可能原因？
<details><summary>答案</summary>

目录名拼错（必须是 `服务名.service.d`）；文件不是 `.conf` 结尾；没 `daemon-reload`。
</details>
