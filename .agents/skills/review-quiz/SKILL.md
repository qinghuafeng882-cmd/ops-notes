# 间隔复习快问快答（D+1 / D+3 / D+7）

## 什么时候用

对已完成的 `labs/` 实验笔记执行 `D+1`、`D+3`、`D+7` 间隔复习自测、批改打分并更新复习记录时使用。

## 执行步骤

1. **先读对应笔记与当周速查表**：
   - 读取要复习的 `labs/*.md`（单篇或多篇合并）和对应的 `cheatsheets/weekN-*.md`，核实课堂上实际讲过、做过的内容及底部「复习记录」当前状态。
2. **核对前置复习记录**：
   - 做 `D+3` 时若 `D+1` 仍为 `[ ]`，先查该笔记与 `git log`；若确认未做，向用户核实后标注 `- [ ] D+1（未做，由 D+3 一并覆盖）`，绝不凭空补勾 `[x]`。
3. **一次出 5 道题，等用户在对话中作答**：
   - **一题只问一件事**：不叠问、不连问、不套问；
   - **严格不超纲**：只考对应 `labs/` 笔记和 `cheatsheets/` 里出现过的概念、命令、参数、报错和排障结论；
   - 优先覆盖上次课后题、上一轮复习的扣分点，以及易混点（如变量差异、继承规则、报错码分流、命令拼写）。
4. **统一批改并打分（满分 5 分，可给 0.5 分）**：
   - 明确指出结论对错、命令/指令/变量名拼写错误，以及机制表述偏差（例如把「下层写了任意一条，上层全部不继承」说成「后面覆盖前面」）；
   - 多篇合并复习时，分别写清各篇分项得分与合计得分（如 `1/1（合并复习，五题合计 4.5/5，不是本篇单独 5 题）`），不虚标单篇满分；
   - 若某题因出题超纲导致用户答不出，该问不扣分并主动说明。
5. **更新笔记的「复习记录」并推送**：
   - 将对应项更新为 `- [x] D+N（MM-DD，得分与扣分点/覆盖点简述）`；
   - 检查无敏感信息后，按 `AGENTS.md` 执行 `git add`、`git commit`、`git push`。

## 不要做

- 不要在一道题里塞多个小问（禁止叠问、连问、套问）。
- 不要考课堂和笔记里没讲过的参数、选项或超纲写法。
- 不要编造或凭空补勾未做过的复习记录，也不要把纠正后的答案当成首答得分。
