# 间隔复习快问快答（D+1 / D+3 / D+7）

## 什么时候用

对已完成的实验笔记做 D+1、D+3、D+7 复习自测时。

## 我会给你

- 要复习的课程编号或笔记路径（单篇或多篇合并）
- 本次是 D+1、D+3 还是 D+7
- （可选）要覆盖的重点或上次扣分点

## 你要做的

1. **先读对应笔记和当周速查表。** 确认笔记里实际讲过、做过的内容，以及底部「复习记录」的当前状态。
2. **核对前置复习记录。** 做 D+3 时如果 D+1 还没打勾，先查笔记和 `git log`；找不到记录就问我确认，确认没做过则保留 `- [ ] D+1（未做，由 D+3 一并覆盖）`，绝不凭空补勾。
3. **一次出 5 道题，等我在对话中作答。** 出题规则：
   - **一题只问一件事**：不叠问、不连问、不套问。
   - **严格不超纲**：只考对应 `labs/` 笔记和 `cheatsheets/` 里出现过的概念、命令、参数和排障结论。
   - 优先覆盖上次课后题或前一轮复习的扣分点、易混点（如变量差异、继承规则、报错码分流）。
4. **统一批改并打分（满分 5 分，可给 0.5 分）。**
   - 指出结论对错、命令/指令/变量名拼写错误，以及表述不准确的地方（例如把「下层写了任意一条，上层全部不继承」说成「后面覆盖前面」）。
   - 如果某题因 AI 出题超纲导致答不出，该问不扣分并主动说明。
5. **更新笔记的「复习记录」。** 将对应项改为 `- [x] D+N（MM-DD，得分与扣分点简述）`。

## 不要做

- 不要在一道题里塞多个小问（不要叠问、连问、套问）。
- 不要考课堂和笔记里没讲过的参数或写法（不要超纲）。
- 不要编造没做过的复习记录。
